## Boundary Overlay Tool

Takes the actual boundary of a city or country and places it over another
location on the map, preserving true physical size and shape regardless of
latitude. Search any two places, or draw a custom contour by hand. No backend,
no API key — runs as a single HTML file against Leaflet and the OpenStreetMap
Nominatim API.
